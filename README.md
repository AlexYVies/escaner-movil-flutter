# Escáner Móvil — Flutter Document Scanner (Photos to PDF)

**Cross-Platform Flutter App to Capture, Crop, Reorder, and Export Photos as High-Quality PDFs**  
Built with **Flutter**, **Dart**, **Material 3** (Light/Dark theme persistence), `image_picker`, `image_cropper`, and `pdf`.

> 🇪🇸 **Resumen en Español:** Aplicación móvil multiplataforma en **Flutter** para capturar, recortar, reordenar y exportar fotografías a **PDF** sin perder calidad, con soporte de tema claro/oscuro persistente y guardado/compartición nativa.

---

## Features

- **Capture & Import:** Take photos with the camera or import multiple images from the gallery (`image_picker`).
- **Crop & Adjust:** Precision image cropping before export (`image_cropper`).
- **Reorder Pages:** Arrange scanned pages in any order before generating the PDF.
- **High-Quality PDF Export:** Generate multi-page PDFs (`pdf`), save to device (`file_saver` / `file_selector`), open (`open_filex`), or share (`share_plus`).
- **Material 3 UI:** Light and dark themes persisted with `shared_preferences`.

---

## Quick Start

```bash
flutter pub get
```
